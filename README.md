# RouteMate AI — Campus Transit

A polished React + Vite hackathon demo for intelligent campus transportation.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Demo features
- Student dashboard with RouteMate AI branding and personalized commute snapshot
- Hyderabad-inspired demo routes, route search, selection and stop selection
- Simulated moving bus marker with adjustable route progress and auto movement
- Live-style ETA and leave-home calculator (bus ETA, walking time, safety buffer)
- Editable student profile (Krithika / BK defaults)
- Mock AI commute assistant with suggested prompts
- Admin fleet dashboard with simulated operational statistics
- Responsive desktop and mobile layout

## Demo notes
All route, GPS, ETA, occupancy and fleet values are simulated in the browser. No API key, backend, database, or authentication is required. The map is a custom schematic route visualization, not a live geographic map.

## Future integration seams
- Replace `src/data.js` with API-backed route and fleet data.
- Feed GPS coordinates into the map marker in `MapPanel`.
- Replace the ETA calculation in `App.jsx` with a traffic-aware ETA service.
- Connect notifications and driver telemetry through a backend service.
